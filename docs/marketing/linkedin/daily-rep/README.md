# «Daily Rep» — daily LinkedIn series for Hardo App

One post per day, one real IB interview question per post. The format is
defined in `.claude/skills/linkedin-daily-rep/SKILL.md`; generate a post with
the `/li-daily` command (optionally passing a date or topic override).

- **Numbering:** #001 = 2026-07-06; rep number = days since start, inclusive.
- **Rotation:** weekday category (Technical / Behavioral / Trap / Drill /
  Rebuild / Radar / Mindset) × 4-week topic curriculum.
- **Automation:** a daily Claude Code trigger generates the post each morning;
  copy the body into LinkedIn and put the CTA + link in the first comment.

This folder is the archive. Save published posts as
`YYYY-MM-DD-rep-NNN.md` so future sessions can grep past topics and avoid
repeats.
